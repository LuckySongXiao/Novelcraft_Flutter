# NovelCraft 功能使用说明（1.0.0+34）

## 1. 首次使用

1. 启动应用后先进入“AI 配置”。
2. 在对应平台填写 API 地址、模型和凭据，点击保存并测试连接。
3. RWKV Cloud 官方端点按 1.5B、3B、7B、13B 分开保存；模型列表来自当前端点的 `/v1/models`。
4. Cloudflare Access 凭据只在应用内填写，不要写入源码或分享包。

## 2. Agent 与写作

- MainAgent 和 SubAgent 可分别选择平台与模型，模型为空时使用平台默认模型。
- 多智能体写书可启用 G1K 预设：7.2B 负责规划/润色，2.9B 负责正文。
- 章节正文经过长度、复读、问答串入、Markdown 残留和 AI 味检查；不合格内容不会覆盖原稿。
- 章节保存完成后，可按开关自动同步人物履历、剧情、世界观和时间线状态。

## 3. 客座读者与审查团队

在“AI 配置 → 客座读者与 13B 高级审查员”中：

1. 填写 13B 审查员平台和模型，默认建议使用 `RWKV Cloud::official-13b`。
2. 配置最多三位客座读者。每位读者可单独设置平台、模型、称呼和品味描述，例如“网文读者：关注节奏和爽点”。
3. 勾选读者开关并保存。
4. 在项目概览点击“7B 全书审查并改进”。客座读者先留言，7B 汇总后审查，随后向 13B 请教。
5. 13B 可以认可 7B 的方案，也可以提出修订意见；最终意见会一并交给 3B 写手。
6. “查看审查留言”可按章节查看每条意见的来源和建议。

审查结果会保存到项目本地存储，不会改变章节，除非 3B 改写通过正文质量闸门。

## 4. 项目与档案

- 项目管理菜单中的“导出电子书”进入 EPUB/Markdown/TXT 导出页面。
- 章节顺序统一按分卷序号、章节序号排列。
- 项目概览中的“审查并校准项目档案”会修正项目名称、清理已删除章节/分卷对应的孤儿档案。

## 5. 便携版运行

- Windows：解压完整 ZIP 后运行 `novelcraft.exe`，不要只复制 exe 文件。
- Android：安装正式签名 APK；首次使用需要在 AI 配置中填写自己的服务凭据。
- 本版本未连接实体 Android 设备进行安装测试，APK 已完成包名、版本码和正式签名校验。
