## 2. 清洗规则（纯 Dart，`lib/ai/utils/chapter_meta_cleaner.dart`）

### 标题（只处理约定形态 `前缀《章名》`）

| 输入（真实库） | 输出 |
|---|---|
| `第一卷·第三章·《青铜面具的秘密（约600字》` | `第一卷·第三章·《青铜面具的秘密》` |
| `第一卷·第七章·《裂痕（700字》` | `第一卷·第七章·《裂痕》` |
| `第二卷·第一章·《夜行者（约10章》` | `第二卷·第一章·《夜行者》` |
| `第二卷·第六章·《净化仪式（约700字）开局状态：》` | `第二卷·第六章·《净化仪式》` |
| `第一卷·第六章·《第7/10章》`（纯章号） | `第一卷·第六章·《第六章》`（兜底名） |
| `第一卷·第一章·《闯入者》`（本来就干净） | **不改动** |
| `第一章 · 少年出乡`（老项目自由标题） | **不改动**（非约定形态，宁可不改） |

### 梗概（一句话，≤120 字）

去 Markdown 标题（`#{1,6}`，**含无换行的一整行**）→ 去列表符/星号 → 去字段标签
（`本章目标：` / `核心事件：` / `开局状态与目标` …）→ 去 Markdown 表格行与管道符 →
去章节规模提示（`（11-15章）`）→ 复读兜底（`ngram>0.20` → 回落章名）→ 按
「句末 → 分句 → 硬截」三级收尾。

**只写 `title` / `summary` 两列**；正文复读（150+ 章）留给逐章确认/重写。

## 4. 本轮顺带修掉的解析器缺陷（由真库用例暴露）

| # | 缺陷 | 修法 |
|---|---|---|
| 9 | `（约N章）` 章数提示未被识别（`夜行者（约10章`） | 规模提示正则覆盖 `字|章` + 区间 `N-M` |
| 10 | `第10_10章` 这类分隔符被下游改写后漏网 | 章号分隔符认全 `/ ／ _ - ~ . ．` |
| 11 | 一整行的多段大纲（`##`/`###` 无换行）→ 字段名混进梗概 | `extractBrief` 按 `#{1,6}` 切「逻辑行」 |
| 12 | 表格行混进梗概（`\| 角色 \| 身份/状态 \|`） | 整行丢弃表格行 + 剥管道符 |
| 13 | 行首标签与正文粘连（`本章目标-陈三…`、`核心事件：主角…`） | 行首标签剥离 + 无歧义标签全局剥离 |
| 14 | 标签被从中间切开留下孤零零尾巴（`…潜在纽带。埋下`） | 切点回退到上一个句末（尾巴 ≤20 字时） |
| 15 | 梗概硬切在半句 | 截断改为「句末 → 分句 → 硬截」三级回落 |
