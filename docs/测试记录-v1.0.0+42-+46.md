## +42：AI 运行时预算（2026-10-08）

**问题**：用户设 25K 上下文不生效。
**定位三坑**：① 档位表 12 档无 24K/25K（现 14 档）；② 窗口只在「保存 provider」时刷新 → 加 `_syncContextWindowFromModel()`（initState post-frame）；③ `_SamplingThinkingCard._collectAndPersist` 漏传两字段，每保存一次采样参数就抹掉用户设的值。
**验证**：`tools/context_window_selftest.dart`（27 例，B5 锁「25K 窗口输出 14080 > 16K 窗口 9011」）全绿；Release 启动存活验证通过。

## +43：NG 率治理（2026-10-09）

**问题**：用户真实库「夜闯寡妇村」30 章 NG 率 30%（6 章正文空、3 章字数不足）；根因是 `summary`/`title`/`notes` 里混着「第一章：祭祀之夜（700字）##」这类生产元信息 → 模型照着坏大纲写短 → 过不了 3200 字闸 → 恶性循环。
**交付**：`outline_repair_text.dart`（净化/结构化/渲染，目标字数由程序写死）、章节标题解析、`repairOutlineAndRewrite`（先调大纲再重写）。
**验证**：`outline_repair_selftest` 40 例全绿（用例全部取材于真实库污染值）；双端构建 + 启动存活验证通过。

## +44：规划-续写-润色管线（2026-10-10）

**问题（用户原话）**：草稿按要求重写后正文总篇幅未达预期，且章节状态未做变更。
**工艺（用户拍板）**：达标口径 ≥3200 字；续写起点由程序判据决定；润色用主 Agent 模型。
**交付**：`chapter_plan_text.dart`（切片规划解析/兜底/分块/回声剥离）+ `ChapterRewriteService.rewriteWithPlan`（plan→write 逐片→补片≤2→质量闸→900 字块逐段润色→Draft→Completed+履历+进度刷新）。
**验证**：`chapter_plan_selftest` 42 例全绿；真机实测单章「字数达标」；启动存活验证 PID 9496。

## +45：选节 AI 采纳应用（2026-10-10）

**问题（用户原话）**：续写字数依然未达标；选中文本续写/润色/扩写后没有采纳确认，采纳后应「续写插下一段、润色扩写替换所选段」。
**交付**：`selection_apply_text.dart`（插入/替换纯函数）+ `SelectionEditService` 字数纪律（续写 1200/扩写 ×2 clamp）+ `chapter_ai_panel`「采纳应用」确认对话框 + `chapter_preview_page` 落库与回填 + `entity_page` 预览回填。
**验证**：`selection_apply_selftest` 15 例全绿；i18n 三批共 38 词条对称；启动存活验证 PID 720。

## +46：复读问题（2026-10-11，本轮）

**现象**：严格防复读参数下大纲修订输出整段复读并持久化进 notes（双层前缀「本章目标：本章目标：」）；项目体检 7 警告。
**取证结论**：停止符不是被正则剥掉，而是无状态路由从未下发 stop_tokens（详见交接文档 §3 取证表）；另有 alpha_presence 被夹 [0,0.5]、dry_* 服务端忽略两个既有事实。
**修复**：A 无状态路由补发 stop_tokens；B `RepetitionGuard`（n-gram 0.30 阈值 + 紧邻重复行 + 段落重复）；C parse 剥复读标签 + `stripFieldLabels` + 落库前复读闸（拦截文案 i18n 键 `CRW.OutlineRepeatBlocked`）。
**验证**：

- `tools/repetition_guard_selftest.dart` 16 例全绿（复读样本 ngram=0.655 命中；正常散文/大纲 0.00 不误杀）；
- `tools/outline_repair_selftest.dart` 52 例全绿（F1-F7 锁双层前缀与幂等）；
- **13 个离线自检全部通过**（chapter_plan 42 / chapter_title 17 / context_window 27 / entity_profile / entity_update / json_scan / kv_key / outline_repair 52 / repetition_guard 16 / sanitizer 28 / selection_apply 15 / style_digest 27 / style_rule 40）；
- `tools/analyze_inprocess.dart`：lib 235 文件 error 0 warning 0；
- i18n：1163 调用点 / enStrings 4625 词条 / 英文表缺失 0；
- `dart format` 全部格式化。

**待真机回归**（构建后）：重跑一次「智能修复全部草稿章」确认 ① 不再出现双层前缀 ② 复读输出被拦截并提示 `CRW.OutlineRepeatBlocked` ③ 正常章节照常通过。
