# NovelCraft 打包指南：便携式 EXE 与 APK

> 结论先行：**推荐走「GitHub Actions 云构建」**——代码推上 GitHub 后点一下
> 即自动产出便携 EXE 与 APK，无需任何本地环境。

## 三条路径对比

| 路径 | 前置条件 | 耗时 | 适合谁 |
|---|---|---|---|
| ① 云构建（推荐） | 仅 GitHub 账号 | ~10 分钟（首次 ~15） | 所有人 |
| ② Windows 本地 | Flutter + VS2022 C++ 工作负载 | ~5 分钟 | 有 Windows 开发机 |
| ③ Android 本地 | Flutter + Android SDK + JDK17 | ~10 分钟 | 有配置好的环境 |

---

## ① 云构建（零环境，推荐）

1. 把本仓库推送到 GitHub（含 `.github/workflows/build_release.yml`）
2. 打开仓库页 → **Actions** 标签 → 左侧 **Build Release Packages** → 右侧 **Run workflow** → 确认
   （或：推送任意 `v*` 标签自动触发，如 `git tag v1.0.0 && git push origin v1.0.0`）
3. 等 ~10 分钟，进入该次运行页面底部 **Artifacts**，下载：
   - `NovelCraft-Windows-便携版` → 解压出的文件夹**整体拷走即用**（免安装，绿色便携）
   - `NovelCraft-Android-APK` → `app-release.apk` 直接装到安卓设备

## ② Windows 本地一键出便携 EXE

前置（只装一次）：Flutter SDK + Visual Studio 2022（勾选「使用 C++ 的桌面开发」）。

双击 `scripts\build_windows_portable.bat`，成功后：

```
build\windows\x64\runner\Release\   ← 这个目录整体就是便携版
```

压缩成 zip 拷到任何 Windows x64 机器解压即用（免安装、免运行库——Flutter
自带所需 DLL）。

## ③ Android 本地一键出 APK

前置：Flutter + Android SDK（cmdline-tools 并接受 licenses）+ JDK 17。

```bash
export ANDROID_HOME=/path/to/android-sdk
bash scripts/build_android_apk.sh
# 产物：build/app/outputs/flutter-apk/app-release.apk
```

---

## 签名说明（APK）

当前 `android/app/build.gradle.kts` 无 `key.properties` 时自动退回 **debug
签名**——可直接安装，但**不适合上架/分发**。正式分发请：

```bash
keytool -genkey -v -keystore ~/novelcraft.jks -keyalg RSA -keysize 2048 \
        -validity 36500 -alias novelcraft
```

创建 `android/key.properties`：

```properties
storePassword=你的密码
keyPassword=你的密码
keyAlias=novelcraft
storeFile=/绝对路径/novelcraft.jks
```

构建脚本会自动读取该文件使用正式签名（build.gradle.kts 已内置该逻辑）。

## 已知环境限制（为什么推荐云构建）

- Flutter **不支持在 Linux 上交叉编译 Windows EXE**（需要 Visual Studio 工具链）
- Android Gradle 构建的 Kotlin 编译峰值内存较大（默认 JVM 堆 8G），低内存容器
  （如 4G）容易在 `:gradle:compileKotlin` 阶段假死；GitHub 标准 runner（7G+）
  无此问题
