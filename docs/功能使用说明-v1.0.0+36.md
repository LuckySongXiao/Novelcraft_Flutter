# NovelCraft 功能使用说明（1.0.0+36）

更新日期：2026-10-07。

## 本版主要变化（相对 1.0.0+35）

本版针对**手机端真机实测**暴露的问题做修复，并改造了全书写作的编排拓扑：

1. **串行写书输出提纯**：线性 state 写作链路在正文之前泄漏智能体自我介绍、
   「修订稿」抬头、章节元信息区块的问题已修（新增正则提纯 + 800 字长度安全阀，
   避免长章被误吞）。
2. **云端 RWKV state 落到客户端本地**：会话粒度 = **作用域 × 角色**，
   规划组用 `<书名>::plan`、写作组用 `<项目 id>::chapter::<章 id>`；
   同一会话的写入在客户端排队，跨章并行不再互相污染。
3. **章节审核通过后自动同步设定**：会更新人物管理中的角色信息与角色履历，
   以及世界观各子项的内容信息与状态履历。
4. **编排拓扑**：主线大纲**串行**、支线（分卷/章节）大纲**并行**、
   单章正文**串行**（每章各自一条状态链）、全书章节**并行**同时开工。
   这是当前最适合 RWKV 模型及其 state 机制的路子。
5. 底部状态栏版本号不再写死（此前一直显示 `v1.0.0+23`）。

## 一、安装与升级

- Windows：将 `novelcraft_1.0.0+36_windows_release.zip` 解压到新目录，运行其中的
  `novelcraft.exe`。必须保留同目录的 DLL 和 data 文件夹，不能只复制 EXE。
- Android：安装 `novelcraft_1.0.0+36_release.apk`。应用包名仍为
  `com.novelcraft.novelcraft`，版本码为 36。请直接覆盖升级，勿先卸载以免丢失应用私有数据。
- Windows 便携版表示无需安装程序，用户数据仍在 `%APPDATA%\NovelManagement`，
  不在 EXE 旁。升级前可备份该目录。Android 数据保存在应用私有目录。
- AI 服务地址、模型及凭据需要在“AI 配置”中自行设置；发布包不包含用户的 API 凭据
  或书籍数据库。

## 二、进入 Prompt 配置

入口有两处：

1. “设置 → 写作工艺 Prompt 模板”。
2. 多智能体写书向导中，点击“配置各工艺节点 Prompt 模板”。

列表显示每个节点当前使用的模板，以及保存的自定义模板数量。模板配置全局生效，
同一设备上的书籍共用；没有配置过的节点使用内置默认模板。

本版开放 40 个提示词配置项：31 个写书、审查和设定更新节点，以及 9 个按语言区分的
修炼体系 / 双代理资源模板。

| 工艺环节 | 可编辑内容 |
| --- | --- |
| 大纲规划 | 主编及规划写手角色、主线大纲、分卷大纲、章节大纲 |
| 主笔写作 | 主笔角色、单笔直书、分段串行、续写优选候选 |
| 团队写作 | 组长及偏向写手角色、派活、分段写作、验收、返工、组长补写、整章拼接润色 |
| 续写优选润色 | 主编润色角色、正文片段润色 |
| 正文纠偏 | 纠偏写手角色、污染片段补写 |
| 内容审查 | 7B 审查、13B 复核、客座读者评论、审查后写手改进，各自的角色与任务提示词 |
| 设定履历 | 档案管理员角色、事实抽取及格式纠偏 |
| 双代理协作 | 需求整理、主编写作、草稿精修的中英文系统提示词 |
| 修炼体系 | 中英文系统提示词和英文任务资源模板 |

各工艺只调用其实际经过的节点。例如单笔直书不调用团队派活；没有启用对应模型或
业务入口时，修改相关模板不会自动启用该功能。

## 三、新建、修改、选择与保存

1. 打开需要调整的节点，先查看内置 Prompt 和“动态变量参考”。
2. 点击“复制为新模板”，输入容易识别的名称，例如“悬疑慢节奏”“轻快对白”。
3. 修改 Prompt 正文。可以调整语气、节奏、描写重点和任务说明，必须保留动态变量。
4. 点击“保存模板与选择”。保存成功后，本节点使用当前选中的模板。
5. 再次复制可以创建更多模板；下拉框可在该节点已有模板之间切换。切换后也要点击保存，
   才会改变运行配置。
6. 恢复默认：在下拉框选择“内置默认”并保存。已有自定义模板仍保留。
7. 删除：选中自定义模板，点击“删除当前模板”，再保存。该节点恢复内置默认。

内置模板只读，防止默认工艺丢失。未保存就离开时会提示放弃修改。保存失败会显示错误，
并继续使用此前已保存的配置。

## 四、动态变量与输出格式

写作节点使用 `{{变量名}}`，例如 `{{cfg_bookTitle}}`、`{{chText}}`、`{{targetChars}}`。
参考区会解释每个变量的内容；运行时由系统填入书名、大纲、正文片段、评论或目标字数。

旧资源模板保留 `{变量名}` 格式，例如 `{TaskName}`。不同节点的变量不通用，
请从该节点默认模板复制，不要把其他节点的 Prompt 整段移入。

保存时检查空内容、重复名称、未知变量、缺失变量和不完整的双花括号。变量内容只替换一次，
小说正文中的花括号不会被当作新的指令变量继续替换。

派活、验收、审查、履历抽取等节点依赖 JSON 输出。请保留默认提示词中的字段名和结构。
变量检查不等于对提示词语义的审核，任意删除 JSON 要求可能使模型输出无法解析；
原有解析、纠偏和质量检查仍继续执行。

## 五、生效时机与配置备份

- 保存成功后，新启动的任务使用选中模板。
- 多智能体写书、内容审查和设定更新服务持有配置快照。正在运行的任务不会中途切换为
  另一套模板；请结束当前任务后重新启动。
- 双代理及修炼体系资源模板在后续读取提示词时使用已保存配置。建议任务运行期间不更换模板，
  避免前后阶段风格不一致。
- Windows 配置文件：`%APPDATA%\NovelManagement\ai_config\writing_prompt_templates.json`。
  迁移个人模板可在关闭应用后备份 / 恢复此文件；不要改动其中的版本号或模板标识。
- Android 使用应用私有存储，重启及正常覆盖升级会保留配置。本版没有单独的模板导入导出按钮。
- 如果配置损坏，页面会显示警告，并回退内置模板；不会在读取时覆盖原文件。
  再次保存新配置会替换原配置。

## 六、其他已有功能

在“AI 配置”设置模型平台、端点和模型；项目管理可进入 EPUB / Markdown / TXT 导出。
章节按卷号、章号排序。项目概览提供档案校准、内容审查和留言查看入口。

本版没有改变原有模型路由、审查上下文长度、改写预算及档案校准范围。此前已知的长章截断
与方案采纳问题仍然存在；对重要书稿使用前请先保留正文副本。详细未完成项见本版本交接文档。
