## 2. 为什么分成「可截断」与「需重写」

复读章有两种形态：

| 形态 | 特征 | 处置 |
|---|---|---|
| **前半健康 + 后半循环** | 健康前缀 ≥ 全文 30%，退化后缀 ≥ 25% | ✅ **可截断**：在退化起点切掉，收在句末 |
| **整篇退化** | 复读率 0.9+、段落重复率 0.9+（唯一内容只剩个位数百分比） | ❌ **需重写**：截断只能留下几百字残篇，不如重写 |

「可截断」样例：

```
第二十二章   ngram=0.85 para=0.60  6656 字 → 保留 4506 / 丢弃 2150
第五章       ngram=0.81 para=0.65  6278 字 → 保留 4408 / 丢弃 1870
第十三章     ngram=0.65 para=0.30  6901 字 → 保留 3860 / 丢弃 3041
```

「需重写」样例：

```
第二十三章   ngram=0.98 para=0.00  42157 字 → 无可保留前缀
第七章       ngram=0.96 para=0.94   6541 字 → 唯一内容不足 6%
```

## 3. 顺带发现：部分存量正文含「大纲污染」

扫描预览里看到正文中混着生成期的结构标记，例如：

```
第三十六章：… ## 本章大纲（87%） ### 1. **主线剧情：** - **主线剧情是关于主线剧情的…
第六章：    … 4862343267989547896987228630158905 【段落1 · 第1段】 林婉清在祠堂前空地发现一个…
```

- `【段落N · 第N段】` 与 `## 本章大纲（87%）` 是**生成期段落标记/大纲**；
- `4862343…` 是采样退化产生的**数字串垃圾**。

这些形态 `_cleanFinalChapter` 现在**能**清掉（`【段落\d+[^】]*】` 规则已存在），
说明这批正文是**更早版本**落库的历史数据。它们集中在已软删除的测试项目里。

* 需重写 → 显示「需重写」标记，不给截断按钮（走单章重写流程）。
